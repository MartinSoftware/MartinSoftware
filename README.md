### `> sobre-mi.md`

Estudiante de Ingeniería de Software en la **UTP**, construyendo aplicaciones reales desde hace un buen rato — desde apps móviles para gestión de consumo de agua, hasta herramientas de escritorio para la comunidad de Source Engine, pasando por sistemas de gestión documental para una institución educativa.

No me limito a un solo stack: si el problema pide Kotlin, uso Kotlin. Si pide Python y una interfaz de escritorio, uso PyQt6. Si pide algo para el navegador, ahí está React/Astro.
